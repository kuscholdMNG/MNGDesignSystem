# Legacy exports — frozen 2026-10-13

The exports in this folder (`mng-design-system-export/`, `mng-ads-export/`; `mng-buttons-export/` was deleted 2026-10-14) were made between 2026-09-24 and 2026-10-09 in custom formats (`mng/tokens@1`, `mng-design-system/tokens@1`, Figma layer trees). They are **no longer updated**, and each folder is deleted once its components have a new export (git history keeps the old files).

New token and component exports follow `EXPORT-STANDARD.md` at the top of the repo (DTCG `.tokens.json`, `components/<layer>/<slug>/`, generated `dist/` files). **2026-10-14:** `mng-buttons-export/` deleted (replaced by `components/core/`, 8 button families). Old versions aren't kept while the formats are being settled (Karl).

The design system was renamed **MNG Web Design System** on 2026-10-14. These frozen exports keep the old name ("MNG Design System", `mng-design-system-export/`, `mng-design-system/...@1`) so links from other projects keep working.
