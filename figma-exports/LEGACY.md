# Legacy exports — frozen 2026-10-13

The exports in this folder (`mng-design-system-export/`, `mng-buttons-export/`, `mng-ads-export/`) were made between 2026-09-24 and 2026-10-09 in custom formats (`mng/tokens@1`, `mng-design-system/tokens@1`, Figma layer trees). They are kept as they are and are **no longer updated**.

New token and component exports follow `EXPORT-STANDARD.md` at the top of the repo (DTCG `.tokens.json`, `components/<layer>/<slug>/`, generated `dist/` files). When a component has a new export, its folder here moves to `_archive/`.

The design system was renamed **MNG Web Design System** on 2026-10-14. These frozen exports keep the old name ("MNG Design System", `mng-design-system-export/`, `mng-design-system/...@1`) so links from other projects keep working.
