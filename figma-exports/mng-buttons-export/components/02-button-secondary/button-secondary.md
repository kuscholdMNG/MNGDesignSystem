## Breakpoints

| Breakpoint value | Viewport (MNG templates) | Behavior |
|---|---|---|
| Desktop | ≥640px (768, 1024, 1100, 1280 templates) | Inner button hugs its content |
| Mobile | ≤639px (340 XS-Fold, 360 SM-Mobile templates) | Inner button fills container width, 8px side margin |

*The viewport mapping is the export convention, not a Figma property; Figma only says Desktop / Mobile.*

## Responsive rules

- **Desktop** (`Breakpoint=Desktop`): the inner `Button` frame hugs its label/icon (HUG horizontally) inside an 8px left/right margin wrapper. Buttons in a row or a stack keep a 16px gap.
- **Mobile** (`Breakpoint=Mobile`): the inner `Button` frame fills the container width (FILL) while the wrapper keeps the 8px left/right margin. Stacked buttons use an 8px gap.
- The breakpoint split is Desktop vs Mobile only; there are no per-template variants (340/768/1024/1100/1280). Use Mobile below 640px and Desktop from 640px up unless a layout says otherwise.

## Rendering steps

1. Pick the variant from the Properties table (state comes from interaction: Default → Hover on pointer-over → Pressed on mouse/touch down → InFocus on keyboard focus).
2. Copy that variant's structure from `button-secondary.html` (or build it from `variants[].layerTree` in the JSON).
3. Use the color tokens from `../../tokens.css`, never the hex, so the site theme applies.
4. Replace icon placeholders with the named `Icons` variant (see Dependencies).
5. Check against the preview PNG in `previews/`.
